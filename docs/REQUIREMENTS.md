# 功能范围与验收

## 已确认的产品要求

1. 独立项目位于旧仓库同级，不在旧工作区继续实施。
2. 仅保留打卡上传 → 工时解析与复核 → 按模板生成 Excel → 下载。
3. 原 UI 风格完整保留。
4. 最终交付本地部署和 Vercel 部署两套方案。
5. 不需要登录、账户管理或角色权限，打开即用；保留工时复核与变更记录。
6. 已切换到独立目录并开始代码开发；先提取工时引擎，再接通原 UI 与持久化流程。

## 从现有实现继承的业务合同

- 读取 legacy .xls 时间钟导出，验证扩展名和真实文件格式。
- 保存原件，以 SHA-256 检测重复上传；失败原因可见。
- 沿用 wage-attendance-v2：有效打卡排序，偶数相邻配对，奇数首尾回退并告警；
  在原规则满足时扣一次 0.5 小时午休。空白、非法和不足打卡保持原警告/错误。
- 展示员工身份、完整月度日期、打卡、gross/lunch/net hours、计算方法和异常。
  前端不得另算一套工时。
- 保留原始行与未知字段，以便复核；工时相关删除、修正与导出历史须可追溯。
- 导出使用有效持久化明细；不改变已完成的工时计算口径。
- 只使用正式脱敏模板，不把旧员工工资成品作为模板；生成不能覆盖模板。
- 周末底色、公式、合并单元格、日期/员工匹配和打印设置保持既有行为。
- 不设应用登录与会话；浏览器可直接上传、复核和下载。服务器之间的密钥只用于连接配置，不代表用户账户。

## UI 保留标准

沿用原 OfficeShell 和工时组件。仅有工时功能，首页 `/` 直接显示工时，不保留侧栏或单项分页导航；旧 `/work-hours` 链接保留查询参数跳转首页。
保留品牌图、CSS tokens、字体、间距、表格密度、按钮/提示/空态/错误态，
中英文一次显示一种语言，保留 light/dark/system 主题与移动/桌面适配。
不借拆分重新设计视觉风格。文案仅按独立工时应用范围做必要调整。

## 排除项

卸货单导入、集装箱、托盘/标签、库存、装车/扫码、拆柜计件工资、
全局业务 Dashboard、Native App、原系统的用户管理后台。
登录、账户、会话和角色权限同样排除；工时相关历史只保留数据变更记录。

## 最终验收

| 范围 | 需要的证据 |
| --- | --- |
| 独立性 | 移到干净目录仍可构建运行；无旧路径导入、目录外构建上下文或旧 API 依赖 |
| 计算 | 现有奇偶打卡、午休、空白/错误、身份和月份边界测试迁移并通过 |

| 模板 | SHA-256、公式、日期、工时、周末底色、模板容量及 Excel 打印预览 |

| 访问 | 无账号、无会话即可完成上传到下载；旧登录链接直达工时页；跨站修改请求仍拒绝 |
| 部署 | 本地与 Vercel 分别验证健康状态、完整闭环、持久化、备份和恢复说明 |
